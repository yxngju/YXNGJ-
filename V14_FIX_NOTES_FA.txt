yxngj V14 — اصلاحات بر اساس دو اسکرین‌شات

1) جابه‌جایی بین صفحات فقط با منوی کناری انجام می‌شود؛ wheel و swipe دیگر صفحه را عوض نمی‌کنند. اسکرول داخلی ترمینال، ادیتور و محتوای طولانی همچنان فعال است.
2) قاب کاراکتر X-01 بازتنظیم شد: تصویر کامل، بدون برش و با اولویت نمایش تصویر واقعی؛ شدت canvas پایین‌تر آمده تا چهره و بدن را نپوشاند.
3) ورودی ترمینال واضح‌تر و قابل تایپ شد؛ بعد از اجرای دستور فوکوس به ورودی برمی‌گردد.
4) ادیتور Python ارتفاع بیشتر، caret واضح، Tab چهار فاصله، همگام‌سازی اسکرول شماره خطوط و Ctrl+Enter برای اجرا دارد.
5) پس‌زمینه Cyber Lab افکت کدهای هکری متحرک سبک CSS دارد.
6) اجرای واقعی Python فقط پس از اجرای START_CYBER_LAB.bat و باز کردن http://127.0.0.1:8765/ فعال است. باز کردن مستقیم index.html حالت پیش‌نمایش فایل است و پل Python را فعال نمی‌کند.

این نسخه با بررسی ایستا، syntax check جاوااسکریپت، py_compile و تست ZIP بررسی شده است؛ تست فیزیکی روی لپ‌تاپ کاربر انجام نشده است.
