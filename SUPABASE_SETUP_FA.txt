YXNGJU V60.4 — راه‌اندازی دیتابیس، ورود کاربران و پنل مدیر

مهم: سایت فعلی روی GitHub Pages استاتیک است. فایل‌ها به‌تنهایی نمی‌توانند یک دیتابیس ابری واقعی بسازند؛ باید یک پروژه Supabase به حساب خودت متصل کنی. این بسته schema و کد اتصال را آماده کرده است.

۱) در supabase.com یک پروژه بساز.
۲) از Project Settings > API مقدار Project URL و anon/public key را بردار. فقط همین دو مقدار عمومی را در supabase-config.js جایگزین کن. service_role key یا Database Password را هرگز در فایل‌های سایت/GitHub قرار نده.
۳) در SQL Editor فایل supabase-setup.sql را اجرا کن. در دستور انتهایی ADMIN_EMAIL را با ایمیل اختصاصی مدیرت عوض کن؛ اما ابتدا آن ایمیل را از account.html با Signup ثبت‌نام و ایمیلش را تأیید کن. سپس SQL را اجرا کن تا همان حساب به نقش owner ارتقا یابد.
۴) ایمیل دیگر را جداگانه از صفحه Account ثبت‌نام کن؛ آن حساب فقط user عادی است. ایمیل‌ها را بعداً از Authentication در Supabase تغییر/تأیید کن.
۵) در Authentication > URL Configuration آدرس سایت GitHub Pages را به Site URL و Redirect URLs اضافه کن.
۶) فایل‌ها را در همان GitHub repository قبلی commit/push کن.
۷) پنل مدیر: /admin.html — فقط ایمیلی که در admin_users ثبت شده اجازه ورود دارد.

چه چیزهایی در پنل دیده می‌شود؟ ایمیل ثبت‌شده، نام نمایشی، تاریخ ثبت‌نام، آخرین فعالیت، وضعیت حساب و رویدادهای ورود. رمز کاربران هرگز قابل مشاهده نیست و نباید باشد.

امنیت: جدول‌ها RLS دارند. کاربر فقط پروفایل خودش را می‌بیند؛ مدیرِ ثبت‌شده می‌تواند فهرست کاربران را بخواند. ساخت/تغییر مدیر فقط از SQL Editor انجام می‌شود. قبل از استفاده عمومی، تأیید ایمیل، MFA برای حساب مدیر، محدودیت نرخ ورود، CAPTCHA/anti-bot و بکاپ پروژه را فعال کن.

بازی موبایل: روی کنترل‌های بازی جلوگیری از long-press context menu و انتخاب متن اضافه شده و pointer capture/release برای نگه‌داشتن جهت حرکت اصلاح شده است.

تست محلی: اجرای HTML به‌تنهایی بدون تنظیم Supabase فقط UI را نشان می‌دهد. ورود واقعی، فهرست ایمیل‌ها و پنل مدیر تا انجام مراحل بالا قابل تأیید نیستند.
