YXNGJU V60.1 — راهنمای اجرای محلی

1) فایل ZIP را Extract کن.
2) وارد پوشه yxngju_site_v48_chrome_glass شو؛ همان پوشه‌ای که index.html داخل آن است.
3) در نوار آدرس File Explorer بنویس powershell و Enter بزن.
4) این دستور را اجرا کن:
   py -m http.server 8000
5) در Chrome یا Edge باز کن:
   http://localhost:8000
6) برای توقف سرور در PowerShell کلیدهای Ctrl+C را بزن.

برای تست تغییرات، ابتدا منو و اسکرول صفحات را بررسی کن. سپس بازی‌ها را اجرا کن.
اگر ایرادی دیدی، نام صفحه + کاری که انجام دادی + نتیجه‌ای که انتظار داشتی را بفرست؛ در صورت امکان اسکرین‌شات هم بفرست.

نکته: این نسخه روی کپی پروژه کار می‌کند و جایگزین خودکار مخزن GitHub تو نیست. قبل از جایگزینی، از پوشه مخزن فعلی یک کپی پشتیبان نگه دار.
